# Financial Analysis Dashboard

## Project Overview
This project analyzes a fictional company's financial transactions using Microsoft Excel and Power BI. It focuses on revenue, expenses, net cash flow, transaction status, regional performance, and departmental budget performance.

The goal is to turn raw financial records into clear insights that support business monitoring and data-driven decision-making.

## Dataset
- **Dataset:** Fictional Company Financial Transactions
- **Transactions:** 2,500 synthetic records
- **Date range:** January 1, 2024 – December 31, 2025
- **Currency:** Indian Rupees (INR)
- **Source:** Excel workbook included in this repository

> **Note:** All records are synthetic and intended for learning and portfolio demonstration. They do not represent a real company's financial data.

## Tools Used
- **Microsoft Excel** – Dataset review and preliminary analysis
- **Power BI Desktop** – Interactive dashboard and data visualization
- **Power Query** – Data preparation and transformation
- **DAX** – Measures and financial calculations

## Analysis Covered
1. **Financial Overview** – Key financial performance indicators.
2. **Monthly Revenue vs. Expenses** – Monthly comparison of revenue and expenses.
3. **Department Analysis** – Revenue and expense distribution by department.
4. **Category Analysis** – Financial breakdown by transaction category.
5. **Regional Analysis** – Financial performance across regions.
6. **Transaction Status** – Analysis of completed, pending, and cancelled transactions.
7. **Actual Expenses** – Monthly actual expense analysis.
8. **Budget Analysis** – Comparison of budget and actual expenses by month and department.

## Business Questions
- What are the total revenue and total expenses?
- What is the net cash flow?
- How do revenue and expenses change month by month?
- Which departments and categories account for the highest expenses?
- Which regions contribute the most revenue?
- How many transactions are completed, pending, or cancelled?
- How do actual expenses compare with the allocated budget?
- Which departments have the largest budget variance?

## Dataset Structure
The Excel workbook includes the following source tables:
- **Transactions** – Transaction-level financial records.
- **Monthly_Budget** – Monthly departmental budget, actual expense, variance, and budget utilization.
- **Category_Reference** – Transaction categories and their descriptions.

The workbook also contains supporting analysis sheets and a project guide.

## How to Use
1. Clone or download this repository.
2. Open `Financial Analysis.pbix` using Power BI Desktop.
3. If Power BI requests the Excel source location, update the file path to the downloaded workbook.
4. Refresh the data.
5. Explore the report pages, visuals, and available filters.
